# Privacy

Four Hours stores incident context, sourced assessment facts, authenticated account IDs, classification attestations and report receipts inside the installing site's Forge app storage. Data is used to operate the incident desk, compute reporting deadlines and reproduce decisions.

The standalone replay stores synthetic demonstration records in the visitor's browser. Reset synthetic replay clears those records. It uses no analytics or external model endpoint.

The Teamwork Graph connector indexes only the explicitly synthetic technical service projection. Objects are visible in the Atlassian workspace. Disconnecting removes the connector's graph data. Regulatory evidence remains in Forge storage.

Confluence publication is initiated by the user and creates a workpaper in the selected space under the current user's permissions. Rovo requests use the installation's Atlassian capabilities and access controls.

The installing organisation controls incident retention, Jira permissions, Confluence access and app removal. Contact the repository maintainer through the project's issue tracker for support.
